# Styx

A media system: cameras in, frames out, with image processing and codecs in between. Native first,
on [Lemnos](https://github.com/Prometheus-Dynamics/Lemnos) drivers with Styx's own 3A and ISP, and
libcamera, V4L2 and FFmpeg for coverage.

This is the `next` branch, a rebuild in progress. The working library is on `dev`. Start with
[`docs/design.md`](docs/design.md) and [`AGENTS.md`](AGENTS.md).
