## Build

- One control set every backend maps to (exposure, gain, white balance, focus, frame rate, flips, crop), with ranges and which frame a value applies to.
- Per-frame metadata: the controls in force, sensor timestamp, exposure, gains, lux, colour temperature.

## Proof

Tests: each control's range and default; metadata round-trips.
