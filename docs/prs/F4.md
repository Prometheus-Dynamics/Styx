## Build

- Feature `daedalus`: `FrameLease` as a Daedalus `next` value (`#[derive(Type)]`, key `styx:frame`) in a plain dma-buf memory location (X7), with transfers to the GPU locations, per Daedalus `docs/foreign-values.md`.
- A ring reader node: a graph in another process takes frames from F2's shared ring as `styx:frame` values, buffers held until the graph lets the last value go. Orion has no Daedalus bridge (dropped 2026-11-11), so this is the one way into a graph out of process; in process, frames are handed in directly.
- Daedalus imports a dma-buf's bytes only (fd and length, no format: Daedalus J6). Sampling a frame as a texture by format (NV12 planes, modifiers, chroma) is Styx's, in its own wgpu node.

## Proof

Test: a graph with a producer and a consumer of `styx:frame` runs; the planner inserts a GPU transfer when asked and refuses with both ports named when none exists.
