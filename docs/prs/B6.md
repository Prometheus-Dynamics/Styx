## Build

- Any capture node: UVC webcams through uvcvideo, other boards' capture drivers. Built on Lemnos's `lemnos-v4l2` library (pure Rust V4L2, subdevices, media controller) used as a plain library: no lemnosd needed, so a PC without Lemnos running works.
- DMABUF export where the driver supports it, MMAP otherwise (counted as a copy only when Styx copies). Styx has no V4L2 bindings of its own.
