## Build

- Feature `libcamera`, off by default. Any camera libcamera lists: its streams, its 3A (libcamera's IPA), its controls mapped to Styx's, its dmabufs as FrameLeases without copying.
- No PiSP-specific workarounds in code paths that other platforms take; where one is needed, it's keyed on what libcamera reports, not a board name.

## Proof

Paste: a libcamera virtual or vimc camera in CI giving frames with 0 copies; board run in H7.
