# B7: Choosing a backend

**Group:** B. Cameras

**Wave:** 4

**Needs:** B1, B5, B6

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Creates

`crates/camera/select`

## Read on dev

- `crates/styx/src/capabilities.rs`
- `crates/styx/src/backend_kind.rs`

## Build

- Per camera: native if a native chain exists, else libcamera if it lists the camera, else V4L2. One owner per camera; the reason is logged; config can force a backend.
- The same physical camera seen by two backends is one camera, not two.
- When Lemnos's `uvc` driver claims a USB camera it takes it from uvcvideo: native wins and the camera appears once.

## Proof

Tests: each case picks the right backend; a forced choice wins; a camera seen by libcamera and V4L2 appears once.
