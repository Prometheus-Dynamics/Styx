## Build

- Neutral settings into Lemnos's `pisp` library (front and back end builders, tiling, statistics layouts, used without `device`), posted as jobs on `camera.isp/1` and `isp.pisp/1`. Statistics back to the controller. Two outputs from one pass; sliced back-end passes so a frame's first rows are out early.
- Styx owns the values; the layouts and the tiling are Lemnos's. No uAPI structures in Styx.
