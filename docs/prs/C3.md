## Build

- Tuning ships with Styx's install (`/usr/share/styx/tuning`, from `data/tuning`). A board build can add one (`/etc/styx/tuning` or a configured directory); an added file wins over a bundled one of the same name.
- Module tunings (the OV9782 one from dev) are data files, named by sensor and module, never in code. A generic tuning when nothing matches, and the log says which file was used.

## Proof

Tests: search order; an added file overrides; a missing tuning falls back to generic and says so.
