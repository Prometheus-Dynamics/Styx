## Build

- Vulkan ISP with one shader source, still bit-for-bit with D6. dmabuf import, no per-dispatch wait on the CPU.
- An optional GPU-lease hook the product fills (Lemnos `gpu-lease/1`): asked before GPU work, released after. Off, it costs nothing.
- Format-aware dma-buf import into the GPU (planes, modifiers, chroma) is Styx's own code; Daedalus removed its image import.
